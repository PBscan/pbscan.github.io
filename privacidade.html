Política de privacidade

As aplicações «Alfredo», incluindo a «Alfredo extractos», são de uso estritamente pessoal: o único utilizador é o seu proprietário, que é também o titular dos dados a que acedem.

A «Alfredo extractos» usa a API do Gmail com permissão apenas de leitura para localizar mensagens de um remetente bancário e guardar os ficheiros em anexo no armazenamento privado do proprietário. Não lê outras mensagens, não escreve, não apaga nem altera correio, e não transmite dados a terceiros.

Os dados obtidos através das APIs da Google não são vendidos, partilhados nem usados para publicidade, e o seu uso respeita a Política de Dados do Utilizador dos Serviços de API da Google, incluindo os requisitos de uso limitado.
